## 🏗️ Core Architecture
Gravity is a multi-tier fintech ecosystem designed for precision and scale.

<img src="gravity_asset_manager_identity_1772929801951.png" alt="Gravity Core" width="100%">

### 1. Intelligence Core (Alpha Agent)
*   **Neural Routing:** LLM-driven agents (`Gemini`, `Claude`) acting as quants and risk managers.
*   **Command Terminal:** Native `OpenBB` integration for institutional data and technical analysis.
*   **Autonomous Analysis:** Real-time sentiment and technical signal generation.

### 2. Market Intelligence
*   **Precision Charting:** High-performance candlestick rendering with Volume Profiles and IV Regimes.
*   **Factor Analysis:** Multi-dimensional risk assessment (VaR, Expected Shortfall, Sharpe).
*   **Real-time Streams:** WebSocket-driven data from IBKR, Bybit, and cTrader.

### 3. Execution Engine
*   **Hybrid Bridge:** Direct order routing to Interactive Brokers and Crypto Exchanges.
*   **Algorithmic Edge:** C++ optimized portfolio backtesting and NAV curve tracing.
*   **Position Management:** Dynamic treemaps and sector exposure monitoring.

## 🛠️ User Manual

### Intelligence Terminal
Interact via natural language or direct commands.
- `technical rsi --symbol NVDA --chart true`
- `portfolio.sharpe --assets AMZN,TSLA`
- `market.sentiment --query "semiconductors"`

### Data Visualization
- **Bento Dashboard:** Modular UI for custom workspace configuration.
- **Glassmorphism UI:** High-contrast neon theme optimized for dark environments.
- **3D Event Horizon:** WebGL environment for data-intensive processing states.
